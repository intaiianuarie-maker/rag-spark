**1) [P2] MISSING MOUNT EVIDENCE — a declared shared mount must be proven**
`apps/api/app/agents/lifecycle_routes.py` + `apps/worker/worker/main.py`

- New `mount_evidence_ok(target)`: when `AGENT_STORE_SHARED_MOUNT` is
  DECLARED, the mount table must be READABLE and must contain an entry AT

  `test_host_mode_without_declared_shared_mount_still_admits`.
- Check order: shadow → mount mismatch → mount evidence → containment.

**2) [P2] OCTAL ESCAPES — decoded in ONE pass**
- New `_unescape_mountinfo_path(value)`: a single left-to-right pass that
  decodes any `\NNN` octal sequence (so `\040`, `\011`, `\012` and `\134` are
  all handled) and never re-scans the decoded bytes, so a literal `\134040`
  decodes to `\040` and not to a space (Moby `sys/mountinfo` semantics).
  The previous decoder handled only the space escape, so a nested mount under
  a root containing a backslash or a tab was missed and the shadowed store
  was admitted.

**3) [P3] TEETH SETUP DEFECT — the parent now fails on the BEHAVIOURAL assertion**
- `test_queued_run_refused_when_root_shadows_a_bind_mount` read the rendered
  compose env with `env[key]`, so on the parent (no
  `AGENT_STORE_SHADOW_MOUNTS` key) it died with `KeyError` BEFORE the
  behavioural assertion. The setup now uses `env.get(key)` and deletes the
  variable when the key is absent; the admission assertions are retained.
- The regression was rerun against BOTH parents: it now fails on the
  intended assertion (`assert True is False` — the parent reported
  `admit=True/shared=True`), never on setup/import.

WHY:
- A DECLARED shared mount that the mount table does not show is exactly the
  "the api's file is shadowed / the worker sees depth 0" failure class; the
  readiness must not claim the store is shared without evidence.
- A mount path containing a backslash or a tab is octal-escaped in the
  mount table; a partial decoder silently misses the competing mount.
- A regression that dies in setup proves nothing: the parent must fail on
  the behavioural assertion.

REUSED:

- Moby `sys/mountinfo` unescape semantics (reference implementation named by
